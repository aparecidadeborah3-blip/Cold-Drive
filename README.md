O Cold Drive é um sistema web desenvolvido para controle remoto de carrinhos robóticos utilizando ESP32 e interface criada em Python com Streamlit.

O projeto permite autenticação de usuários, cadastro de robôs, controle manual por comandos direcionais (W, A, S e D), gerenciamento de ações e histórico de comandos enviados ao robô.

A comunicação do sistema foi projetada para funcionar em rede local utilizando integração com ESP32, proporcionando uma interface moderna, intuitiva e funcional para aplicações de automação e robótica.
