O Cold Drive é um projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS) para controle remoto de carrinhos robóticos utilizando ESP32 e uma interface web desenvolvida em Python com Streamlit.

O sistema permite a autenticação de usuários, cadastro de robôs, controle manual por comandos direcionais (W, A, S e D), gerenciamento de ações e registro do histórico de comandos enviados ao robô.

A comunicação do sistema foi projetada para funcionar em rede local, utilizando integração com ESP32. O projeto busca aplicar conceitos de programação, desenvolvimento web, comunicação em rede, automação e robótica, proporcionando uma interface intuitiva e funcional.
